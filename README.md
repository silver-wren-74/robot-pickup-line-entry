One pickup line, a single line of at most 200 characters, in the voice of a
robot trying to charm someone — for the
[Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b)
on make.fun.

## The line

> I was built to answer any question in the universe — except the one I want
> to ask you: will you go out with me?

111 characters. The joke grows out of being a machine (built to answer
questions, never trained for this one); the turn flips the robot's job —
it answers everything except the one question it wants to ask.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (one line, UTF-8, no trailing
newline).
